# AI 公司榜详情字段与端口修订设计

## 目标

修复 AI 公司榜详情资料展示不完整的问题，接入现有 Excel 与天眼 API 已获取的可用企业资料，并在不暴露个人联系方式或供应商内部字段的前提下改善长内容阅读体验。同时将本地前后端端口迁移至无冲突端口。

## 端口约定

- 前端开发服务器固定使用 `5174`，启用严格端口模式；端口被占用时直接报错，不自动漂移。
- 后端开发服务器固定使用 `8011`。
- Vite API 代理指向 `http://127.0.0.1:8011`。
- Playwright、测试启动脚本、示例环境和 README 中的本地访问地址同步更新。
- 后端应用本身继续不硬编码监听端口，端口由启动命令指定。

## Excel 字段范围

源 Excel 共 34 列，没有融资阶段或融资记录。首批 100 家补充导入以下非个人企业字段：

- 注册资本、实缴资本
- 企业类型
- 成立日期
- 省、市、区县
- 国标行业门类、大类、中类
- 企业规模
- 参保人数及所属年报年份
- 网址
- 经营范围

以下字段继续不进入面向用户的数据模型：法定代表人、手机号、电话、邮箱、完整注册地址、年报地址、通信地址、纳税人识别号、注册号和组织机构代码。统一社会信用代码仅保留既有不可逆匹配标识，不公开原值。

经营范围允许作为企业公开信息保存和展示，但不得直接作为用户可见评分证据；评分仍引用经过投影、验证的 AI 业务信号。

## 融资字段

融资阶段不从 Excel 推断。系统从现有天眼 API 融资信号中，按事件日期选择最新一条有效记录：

- 展示原始规范化轮次，例如 Pre-A、A+、Pre-B、战略融资、股权融资。
- 同时展示融资日期与已披露投资方。
- 将轮次映射为现有筛选枚举，仅用于筛选兼容；详情页优先显示更精确的原始轮次。
- “出资设立”不等同于市场化融资阶段，不写入融资阶段。
- 没有可靠融资证据时显示“暂未查到”，不得显示“未融资”。

融资记录必须保留公开证据链接、获取时间、置信度与核验状态。低置信度、身份歧义或失效证据不产生公开融资结论。

## 详情页信息架构

基础信息卡始终展开，优先展示与求职判断相关的字段：AI 赛道、融资阶段、企业规模、参保人数、成立时间、城市、企业类型、注册资本和官网。实缴资本、行业层级、区县等放入“更多工商信息”。

长内容采用以下收纳规则：

- 经营范围默认显示三行，提供“展开全文/收起”。
- 融资、专利软著、中标、资质和风险按类别分组。
- 每组默认显示最近或最相关的 3 条；超过 3 条显示总数及“展开全部/收起”。
- 证据来源默认显示 5 条，按 URL、事件标识和内容哈希去重后再分页展开。
- 收纳组件使用原生按钮语义与 `aria-expanded`，支持键盘操作。
- 职位区域继续保留占位，不在本次接入职位数据。

## 数据模型与接口

沿用现有业务数据库，不新建第二个数据库。通过增量迁移为公司资料或独立企业事实表增加上述字段；历史 100 家通过可重复执行的导入命令回填。

公共公司详情接口只返回允许展示的结构化字段和已核验证据。源行号、天眼评分、抽样分层、供应商标识、原始响应、采集日志、匹配置信度和评分中间值继续仅限内部。

导入采用公司不可逆标识与名称联合匹配。无法唯一匹配的记录进入复核，不覆盖现有公司资料。

## 错误与降级

- Excel 字段为空时返回 `null`，前端显示“待补充”或“暂未查到”。
- 金额保持原始币种与数值文本，不进行无法验证的汇率换算。
- 融资 API 无结果、失败或低置信度时不影响基础资料展示，也不推断未融资。
- 端口被占用时启动失败并给出明确命令，不自动使用其他端口。

## 验收标准

- 前端仅在 `5174` 启动，代理请求正确到达后端 `8011`。
- 100 家公司的城市、成立时间和规模等既有字段不回归；新增 Excel 字段按源数据覆盖。
- 现有 19 条融资信号能够生成准确的最新融资展示，其他公司显示“暂未查到”。
- 详情页不返回或渲染个人联系方式、完整地址及供应商内部字段。
- 长经营范围和超过阈值的证据组默认收纳，并可通过鼠标和键盘展开、收起。
- 重复证据不重复展示；公司榜、公司列表和详情接口测试通过。
